# 🥗 Fitmeal

**Healthy Living, Simplified. A modern web application for healthy recipes, nutrition tracking, and balanced diet planning.**

[![Live Demo](https://img.shields.io/badge/Live-Website-success?style=for-the-badge&logo=netlify)](https://fitmealhealt.netlify.app/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg?style=for-the-badge)](https://opensource.org/licenses/MIT)

</div>

---

## ✨ Features

- **Healthy Recipe Catalog:** Explore a curated collection of nutritious, delicious, and easy-to-make healthy meals.
- **Detailed Nutrition Info:** View precise calorie counts, macronutrients (protein, carbs, fats) for every dish.
- **Why Us Section:** Highlights the core benefits of switching to Fitmeal for your daily lifestyle and wellness goals.
- **Responsive & Modern UI:** Designed with a clean, minimalist green-and-neutral aesthetic optimized for desktop, tablet, and mobile devices.

---

## 🛠️ Tech Stack

- **Frontend:** React.js / Vite
- **Styling:** Tailwind CSS / Modern CSS
- **Deployment:** Netlify
- **Assets / Design:** Custom branding & UI system

## 🚀 Getting Started

### Prerequisites
Make sure you have **Node.js** and **npm** installed on your machine.

### Installation & Local Development

1. Clone the repository:
   ```bash
   git clone https://github.com/ghaisankhazini7-star/Fitmeal.git
   ```

2. Navigate to the project directory:
   ```bash
   cd Fitmeal
   ```

3. Install dependencies:
   ```bash
   npm install
   ```

4. Run the development server:
   ```bash
   npm run dev
   ```

5. Open your browser and visit `http://localhost:5173` to view the app.
